# 房租账单页 · 维护说明

- 账单页网址：https://mauriciachino40-beep.github.io/rent/
- 数据来源：房东桌面上的 `26年房租计算.xlsx`（WPS 编辑）。每月一张表，表名如 `26.11`。
- 表格列（26.11 起）：房间号、房租、上月水、此月水、水费、上月电、此月电、电费、网络费、垃圾费、合计、收款、备注；Q2 水价 4，Q3 电价 1.2；电费、合计四舍五入到元。
- 不要在表里用跨表公式（WPS 对 `'26.10'!E:E` 这类引用会算错），上月读数一律写成数字。

## 每月更新
1. 拿到最新的 xlsx（新月份已填好此月水、此月电）
2. `python3 _tools/gen.py 表格.xlsx /tmp/page.html`（只取最后一个有合计的月份）
3. `python3 _tools/wrap.py /tmp/page.html index.html`，提交推送
4. 建下个月的表：`python3 _tools/make_month.py 表格.xlsx 输出.xlsx 26.11 26.12 '{"605":{"rent":0}}'`（最后一个参数可选，用来改个别房间）
5. 把新表放回桌面

页面只显示本月数据，输入房间号查看；付款在微信群里长按收款码（网页里的个人收款码会被微信拦截，无法长按识别）。
